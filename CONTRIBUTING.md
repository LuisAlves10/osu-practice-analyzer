# Contributing

Read [AGENTS.md](AGENTS.md), the [status](docs/STATUS.md), and the phase gate in the [roadmap](docs/ROADMAP.md). Document the source revision and limitations for any observed game behavior. Label synthetic test inputs and describe how live evidence was obtained.

Submit focused changes with checks relevant to the affected behavior. Keep player data, game assets, local paths and credentials out of issues, pull requests and fixtures.
