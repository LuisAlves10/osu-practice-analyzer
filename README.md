# osu-practice-analyzer

An early-stage, local-first project for players practicing osu!standard in osu!lazer on Windows 11. The goal is to find repeatable difficulties across maps, choose targeted practice, and measure whether improvements transfer.

Independent project. It is unaffiliated with osu! or its developers.

Development status and verification are in [docs/STATUS.md](docs/STATUS.md). The [product scope](docs/PRODUTO.md) and [roadmap](docs/ROADMAP.md) are available in Brazilian Portuguese.

## Development

Phase 0 contains documentation and repository setup. Check changes with `git diff --check`. Runtime setup and test instructions will be added with the first probes.
