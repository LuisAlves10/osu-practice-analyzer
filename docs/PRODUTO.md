# Produto

Para jogadores de osu!standard no lazer que querem escolher o que praticar e avaliar o resultado. O fluxo começa em beatmapset → dificuldade → versão → tentativas comparáveis → diagnóstico → exercício → reteste, com sessões como metadado secundário.

V1 focada em Windows 11, com operação offline, interface em PT-BR e ingestão passiva. O catálogo inclui conteúdo local quando recuperável. A cobertura orienta a interpretação de passes, fails, reinícios e tentativas parciais. O perfil público é contexto opcional. Overlay de gameplay, automação de inputs, calendário obrigatório e análise de mania ficam fora da V1.
